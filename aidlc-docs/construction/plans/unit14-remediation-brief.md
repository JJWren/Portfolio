2. **APPLY (accessibility, major).** Up to 365 tab stops with no way past them. Add a skip link as HTML immediately before the `<svg>`: `<a class="skip-link" href="#visitors-data-summary">Skip the daily detail</a>`, and give the `<details>` summary the id `visitors-data-summary`. In `app.css`, if a visually-hidden-until-focus rule already exists (search for `skip-link`, `visually-hidden`, `sr-only`), reuse it; otherwise add, in the Visitors chart block, `.visitors-chart .skip-link { position: absolute; left: -10000px; width: 1px; height: 1px; overflow: hidden; }` and `.visitors-chart .skip-link:focus { position: static; width: auto; height: auto; overflow: visible; }` plus `.visitors-chart { position: relative; }` (no transition). Add a render-test assertion that the skip link and the summary id are present when the chart renders.
3. **APPLY (framework, major).** `SvgText` returns a `MarkupString` built by string concatenation; a `MarkupString` inside SVG takes a different insertion path in the interactive renderer than the literal SVG elements. Replace it with a `RenderFragment` built through `RenderTreeBuilder`, which follows the same namespace-safe path as `<g>`, `<path>` and the rest: `private static RenderFragment SvgText(string? cssClass, double x, double y, string textAnchor, string content) => builder => { builder.OpenElement(0, "text"); if (cssClass is not null) { builder.AddAttribute(1, "class", cssClass); } builder.AddAttribute(2, "x", VisitorsChartRules.FormatCoordinate(x)); builder.AddAttribute(3, "y", VisitorsChartRules.FormatCoordinate(y)); builder.AddAttribute(4, "text-anchor", textAnchor); builder.AddContent(5, content); builder.CloseElement(); };` Keep the three call sites as `@SvgText(...)` (a `RenderFragment` renders when interpolated). Remove `WebUtility.HtmlEncode` and the `MarkupString` usage (AddContent encodes). Update the helper's summary: Razor reserves the `<text>` tag, so the element is built through the render tree, which keeps the SVG namespace on live re-renders and encodes the content. Confirm the rendered HTML in the tests still contains `<text` elements with the expected attributes.
