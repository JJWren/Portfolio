## Implementation notes

- **`AnalyticsService`**: `public record DailyVisitorPoint(DateOnly Day, int Visitors, bool IsToday);` next to the other records. `public async Task<IReadOnlyList<DailyVisitorPoint>> GetDailyVisitorsAsync(DateOnly from, DateOnly to)`: return an empty list when `from > to`; load `DailySiteStats` rows with `Day >= from && Day <= to` as `AsNoTracking` into a dictionary by day; if `to >= today && from <= today`, compute today's distinct `VisitorKey` count over `PageViews` with `OccurredAt >= start` exactly as `GetSummaryAsync` does (reuse the same `today.ToDateTime(TimeOnly.MinValue, DateTimeKind.Utc)` construction; the `DateTimeKind.Utc` overload matters for Npgsql); build one point per day from `from` to `to` inclusive, in order, with 0 for a missing day and the live value for today (`IsToday` true only for today). A summary comment states the sum-equals-the-tile property (FR-V2).
- **`Services/VisitorsChartRules.cs`**: the members in the plan's Components table, pure and static, with XML summaries. Keep the layout constants in one `ChartLayout` record (`Width` 720, `Height` 240, `Left` 44, `Right` 12, `Top` 12, `Bottom` 28, computed `PlotWidth`, `PlotHeight`). `NiceMax` uses the 1, 2, 5 progression; `Ticks(niceMax)` returns `[0, niceMax/4, niceMax/2, 3niceMax/4, niceMax]` when those are whole numbers, otherwise `[0, niceMax/2, niceMax]`, and for `niceMax` 1 or 2 just `[0, niceMax]` plus the middle when whole; ensure three to five values with no duplicates. Coordinates are formatted with `CultureInfo.InvariantCulture` and one decimal place. `X(index, count)`: for `count` 1 the plot centre, otherwise `Left + index * PlotWidth / (count - 1)`. `Y(value, niceMax)`: `Top + PlotHeight - value * PlotHeight / niceMax`.

Structure: `<section class="card visitors-chart">`, `<h2 id="visitors-chart-title">Daily visitors</h2>`, `<p class="muted">one point per UTC day</p>`; empty state `<p class="muted">Not enough data to chart yet.</p>` when `Points.Count < VisitorsChartRules.MinPoints`; otherwise the `<svg viewBox="0 0 720 240" role="img" aria-labelledby="visitors-chart-title" class="visitors-svg">` containing, in this order: `<g class="grid">` with one `<line>` per tick and a `<text class="axis">` at the left for each tick value (`text-anchor="end"`); `<g class="axis-x">` with a `<text>` per label index (`FormatDay`), the first anchored start, the last anchored end, the rest middle; `<path class="line" d="...">` from `LinePath`; when the last point is today, `<path class="today" d="...">` from `TodayPath` and `<circle class="marker" r="4">` at the last point; then `<g class="days">` with one `<g class="day" tabindex="0" aria-label="...">` per point holding `<rect class="hit" x y width height>` (the column centred on the point, at least 6 units wide, the full plot height) and `<g class="tip">` with `<line class="crosshair">` from the plot top to bottom at the point's x, `<circle class="marker" r="4">` at the point, and a labelled box: a `<rect class="tip-box">` and a `<text class="tip-text">` reading "14 Aug · 12" (today: "14 Aug · today so far · 12"), placed beside the crosshair on the side given by `TooltipAnchor` and clamped so it never leaves the viewBox (compute the box position from the anchor: start anchor draws to the right of x, end anchor to the left; y is the point's y clamped to keep the box inside the plot).
