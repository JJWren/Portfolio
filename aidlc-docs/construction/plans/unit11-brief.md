## What Unit 11 is

Under the BJJ landing flavor the rank bar (`Components/RankBar.razor`) always draws a black belt today. This unit adds a Current Belt (white, blue, purple, brown or black) stored in `SiteContent.CurrentBelt` with the env fallback `SITE_CURRENT_BELT` and the default black, so a deployment that never sets it renders exactly as today; a drawing rule per belt in `app.css` (the inline `style` attribute leaves the component, and after this unit no public component emits one); the degrees cross-check generalized from "the black belt era" to "the last era on the current belt"; a new cross-check that the current belt is not below the road's highest belt; an admin select on `/admin/site`; the migration `AddCurrentBelt`; `.env.example` and README rows; tests.
