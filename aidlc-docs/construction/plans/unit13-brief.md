## What Unit 13 is

The site serves one résumé PDF from the container path in `RESUME_FILE` at `/resume`, counting each download as the `resume-download` analytics event. Today the only way to change the file is to copy it onto the host. This unit lets the admin replace or remove it from the Site content page (`/admin/site`), exactly the way the two owner photos already work (write-through over the configured path), adds a résumé link to the site footer next to the socials, makes the links exist only when the file exists, tags each download with the link it came from, and stops admin sessions from counting toward any analytics event.
