## Implementation notes (the values are pinned by tests; copy them exactly)

- **`Services/SubmissionLimiter.cs`**: the contact limiter's per-key hit list made reusable: `public class SubmissionLimiter(TimeProvider timeProvider, int maxPerWindow, TimeSpan window)` with `public int MaxPerWindow`, `public TimeSpan Window`, `public bool Allow(string key)` (the existing algorithm: prune hits older than the window, refuse when the count is at the limit, else record and allow) and `public TimeSpan RetryAfter(string key)` (the time until the oldest hit still inside the window ages out; `TimeSpan.Zero` when a call would be allowed). `ContactRateLimiter` becomes `public sealed class ContactRateLimiter(TimeProvider timeProvider) : SubmissionLimiter(timeProvider, MaxPerWindow, Window)` keeping its `public const int MaxPerWindow = 3` and `public static readonly TimeSpan Window = TimeSpan.FromMinutes(10)` so `Contact.razor` and `ContactRateLimiterTests` compile and pass unchanged. Add `CommentLimiter` (5 per 10 minutes) and `ReportLimiter` (3 per 10 minutes) as the same kind of sealed derivations, registered as singletons in `Program.cs` beside the contact limiter.
