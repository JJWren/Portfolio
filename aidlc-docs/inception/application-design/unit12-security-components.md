## 3. Dependencies between the pieces

- 12a depends on Unit 11 having removed the last public `style` attribute; 12b depends on 12a only for the middleware order in `Program.cs`. Nothing in 12b touches the header set.
- The theme snapshot feeds two consumers after 12a: `App.razor` (the block) and the middleware (the hash). Both read the same cached snapshot, so they can never disagree within one response.
- The forwarded-headers trust of 12b also governs the address behind the contact limiter and the analytics Visitor Key (both read the connection address); with `TRUSTED_PROXIES` set, a forged `X-Forwarded-For` from a direct client no longer moves either. This is the intended effect and is documented in the README.
- The comment island's `ClientAddress` is the connection address of the page request that rendered it, which is the same request family the limiter keys on for endpoints; a circuit reconnect keeps the original value.
